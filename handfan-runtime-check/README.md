# handfan-runtime-check

Tiny Japanese utility microsite: estimate how long a handheld fan can run from a mobile battery.

## Monetization mode
Affiliate + ads-ready.

Primary monetization:
- mobile batteries
- USB-C handheld fans
- related summer gadgets

Secondary monetization:
- display ads on informational sections if traffic arrives before affiliate links are optimized

## Core hook
`10000mAh でハンディファン何時間もつ？` を30秒で確認できる。

## Likely discovery
- SEO: `ハンディファン 何時間もつ`, `10000mAh ハンディファン 何時間`, `モバイルバッテリー 扇風機 何時間`
- SNS: summer commute / theme park / live event packing threads
