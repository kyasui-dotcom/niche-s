Mini game

提案じゃんけん

5回だけ手を出して、どちらが多く勝つかを見る最小サイズのじゃんけんです。 題材は提案テンポの比喩だけで、契約、法務、税務、許認可、行政手続きなど他の権威領域の判断は扱いません。

開業強化ハブへ戻る 別のミニゲームを見る

Play

1から3のキーかボタンで、5回だけ手を出す

あなたは青、相手は橙です。1回ごとに勝敗を記録し、5回終了時点で勝ち数が多い側の勝ちです。

状態 開始待ち
ラウンド 0 / 5
あなた 0
相手 0
あいこ 0

操作: 1=ぐー / 2=ちょき / 3=ぱー / A=ぐー / Space=ちょき / B=ぱー / R=やり直し / F=フルスクリーン

Tips

短く遊ぶコツ

  1. 1回ごとの勝敗より、5回の合計を見ます。
  2. 操作は3択だけなので、休憩の切り替え用に向いています。
  3. 営業テンポの比喩として軽く遊ぶだけに留めます。

Boundary

扱うのは提案テンポの比喩だけ

このページは娯楽用のミニゲームです。契約条件、法務、税務、許認可、行政提出、労務などの判断や助言は扱いません。
