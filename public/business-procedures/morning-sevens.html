Mini game

朝の段取りセブンズ

中央の基準カードから左右へつなぎ、手札を並べ切る小さなセブンズ風ゲームです。 題材は返信、見積、共有のような軽い仕事ラベルだけで、契約、法務、税務、許認可、行政手続きなどの判断は扱いません。

Play

中央から 1 枚ずつ段取りを広げる

盤面には各列の「3」が置かれています。手札から同じ列の「2」か「4」を出し、次に「1」または「5」へ広げてください。

状態 開始待ち
手札 0
山札 0
得点 0
合法手 0
列完成 0 / 3
経過 0

手札

ルール

  1. 各列の中央「3」から同じ列の「2」「4」だけ出せます。
  2. その後は同じ列で 1 ずつ外側へ広げます。
  3. 合法手がない時は山札を 1 枚引けます。
  4. 3 列ぶん 12 枚を並べ切るとクリアです。

操作: ←→で手札選択 / Enterで出す / Aで山札 / Bで合法手 / Rで再開 / F=フルスクリーン

Tips

短く切り替えるコツ

  1. まずは 2 と 4 を早めに開いて、合法手の選択肢を増やすと詰まりにくいです。
  2. 同じ列を一気に端まで伸ばすと、手札の見通しがよくなります。
  3. これは気分転換用で、実務判断や専門助言の代わりにはしません。

Boundary

扱うのは軽い仕事ラベルの並べ替えだけ

このページは娯楽用のミニゲームです。法務、税務、許認可、行政提出、労務、契約条件などの判断や助言は扱いません。
