How to use

改善1000本ノックの回し方

1. 画面を絞る

トップ、記事一覧、記事詳細、診断フォーム、結果画面、価格ページなど、今いちばん効く画面に寄せます。

2. 狙いを決める

理解速度、CVR、回遊、信頼、継続率など、何を改善したいかを先に決めると打ち手が散りません。

3. 低工数から着手する

最初はマイクロコピー、見出し順、ボタン文言、比較表の見せ方のような低工数から始めるのが現実的です。

4. 計測対象も決める

クリック率、完了率、滞在時間、再訪率のどれを見るかまでセットで決めると改善が回ります。
