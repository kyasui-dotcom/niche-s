FAQ

よくある迷い

このページはRakuten APIだけで動いていますか？

はい。商品候補の取得は Rakuten Ichiba Item Search API のみを使う構成です。

紹介している商品は固定ですか？

固定ではなく、選んだ条件に応じて API 結果から候補を出し直します。

直前に選ぶときは何を見ればいいですか？

最短発送、レビュー件数、冷蔵・常温、ショップ評価あたりを優先して比較すると絞りやすいです。

母の日ギフトの「最初の一歩」を、楽天の商品候補まで一気につなぐ軽量MVP。
